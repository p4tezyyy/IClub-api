# Contributing

Contributions to the unofficial iClub API SDK are welcome.

See the [full contribution guide](docs/contributing.md) for development setup, testing, documentation builds and the release process.

## Before submitting a pull request

1. Check existing [issues](https://github.com/p4tezyyy/IClub-api/issues) and [pull requests](https://github.com/p4tezyyy/IClub-api/pulls).
2. Add tests when you change SDK behavior.
3. Update the relevant Markdown guide and [changelog](docs/changelog.md).
4. Never commit credentials, QR codes, session data or real member records.

Contributions must be licensed under [GPL-3.0-only](LICENSE) and you must have the necessary rights to submit them. This SDK is not affiliated with iClub. Do not bypass authentication or other security controls.
